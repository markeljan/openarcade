The helper used by the local harness must block every `/api` request and every non-loopback host. `S12_URL` defaults to `http://127.0.0.1:4312/` and must be loopback. The JSON contains per-game outcomes and concise diagnostics, not recordings. Browser errors are reported; blocked API failures may be surfaced by application code and should be distinguished from gameplay failures. Local Vite does not implement Vercel Functions, and the existing feedback documentation says Preview and Production can share a database. No integrated write testing is authorized until isolation is confirmed.


## Representative-only checks

Run `node scripts/s12-verify-browser.mjs --representative-only --output <temporary path>` to skip per-game rendering while retaining the catalog label count and representative checks. The result explicitly records `mode: representative-only`; it is not evidence that all game IDs or renders were checked in that run. The player check waits after close and sees no further calls to its instrumented common 2D drawing methods. It does not cover every canvas API, WebGL, timers, or all resources. Visibility is simulated by overriding `document.hidden`; actual backgrounding requires a visible-browser check. Touch input uses two emulated contacts, and physical-device behavior remains unverified.

Canvas smoke requires a draw after watching starts and nontransparent pixels after clearing the previous canvas; it can still pass on a uniform background or loading overlay. It does not establish accurate game content or actual gameplay. Audio checks instrument `AudioContext` construction only; they do not prove absence of HTML media, offline audio, or all audible output.

## Read-only social and coverage checks

After building, start a dedicated preview server, for example `npm run preview -- --port 4313 --strictPort`. Run `node scripts/s12-verify-social.mjs --url=http://127.0.0.1:4313 --canonical=https://openarcade.io --map-images --revision=<SHA> --out=<temporary JSON path>`. This checks homepage and all game HTML before JavaScript, game-specific titles, canonical URLs, OG/Twitter image metadata, PNG response types/dimensions and SHA-256 bytes, plus an unknown-game 404. `--map-images` deliberately requests image paths from the tested origin and records that the advertised public image host was not verified. On a public release omit that flag to request the actual advertised image URL. `--embeds` adds all embed HTML/framing-header and unknown-embed checks after S05 supplies those routes; these are HTTP checks, not iframe execution or X-client proof.

Run `node scripts/s12-coverage.mjs --revision=<SHA> --out=<temporary JSON path>` against the integrated checkout for exact missing image, extra image and unsupported-scoring ID lists. It consumes S02's registry and merged worker shards; it does not execute their claimed terminal tests. Pending scoring is a failing exit by default. `--allow-pending` is informational during rollout and retains the explicit `pending-scoring` status.
